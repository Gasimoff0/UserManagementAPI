# User Management API

A complete, self-contained ASP.NET Core Web API project for managing users. Built to satisfy the requirements of a Coursera peer-reviewed project.

## Features

- **Complete CRUD Endpoints:** Manage `User` entities with GET, POST, PUT, and DELETE operations.
- **In-Memory Storage:** Uses a thread-safe `ConcurrentDictionary` to run standalone without an external database.
- **Input Validation:** Implements robust data validation using Data Annotations (`[Required]`, `[EmailAddress]`, `[Range]`) to reject invalid payload data with 400 Bad Request responses.
- **Custom Middleware:** Includes a `RequestLoggingMiddleware` that logs the incoming HTTP method, path, response status code, and execution time in milliseconds.
- **AI Debugging Context:** Includes code comments detailing where GitHub Copilot was utilized for debugging and logic refinement (e.g., handling null-checks, multi-threading safety with `TryRemove`, and exception handling in middleware).

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (or a compatible .NET version)

## Project Setup & Running the API

1. Clone or download this repository.
2. Open a terminal and navigate to the project root directory.
3. Build the project:
   ```bash
   dotnet build
   ```
4. Run the API:
   ```bash
   dotnet run
   ```
5. The API will start, and the console will output the local URL (typically `http://localhost:5000` or `https://localhost:5001`). 

### Swagger UI
If running in a Development environment, you can access the Swagger UI to test the endpoints interactively at:
`http://localhost:<port>/swagger`

## Endpoints List

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/users` | Retrieves all users. |
| GET | `/api/users/{id}` | Retrieves a specific user by their unique `Guid` ID. |
| POST | `/api/users` | Creates a new user. The `Id` and `CreatedAt` fields are generated by the server. |
| PUT | `/api/users/{id}` | Updates an existing user's `FullName`, `Email`, and `Age`. |
| DELETE | `/api/users/{id}` | Deletes a user by their `Guid` ID. |

## Validation Rules

When creating or updating a user, the payload must conform to the following rules:

- **FullName:** Required, maximum 100 characters.
- **Email:** Required, must be a valid email format.
- **Age:** Required, must be a numeric value between 1 and 120.

Example of an invalid payload (will return `400 Bad Request`):
```json
{
  "fullName": "",
  "email": "invalid-email-format",
  "age": 150
}
```

## Middleware Behavior

The `RequestLoggingMiddleware` intercepts every incoming HTTP request and logs information to the console via the built-in .NET `ILogger`. It measures the time elapsed for the request to process and outputs a log entry resembling:

```
info: UserManagementApi.Middleware.RequestLoggingMiddleware[0]
      HTTP GET /api/users responded 200 in 15 ms
```
